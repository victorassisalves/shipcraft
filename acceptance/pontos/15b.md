## Item 15b: original lefthook route

- Exactly one of four root config names; hook absent or a lefthook launcher. Literal core.hooksPath=.git/hooks works; external paths refuse even with a lefthook launcher.
- Invalid YAML, list commands, extends and jobs at the top or protected block refuse.
- The original route permits only commands in pre-commit; scripts and block filters (glob/files/skip/only/exclude), even empty, refuse. Parallel true uses item 20's route.
- Refusal has three lines naming shipcraft check, before questions or changes, including .git modes.
- shipcraft check priority is maximum+1 (1 without commands), at most 2147483647. Existing priorities must be explicit positive decimal integers. Missing/zero/negative/maximum uses item 20; inherited, noninteger and out-of-range values refuse.
- Other commands/blocks retain semantics, including command filters, environment and stage_fixed.
- An identical Shipcraft command has only run and a strictly greater priority; bytes remain unchanged. Extra keys or insufficient priority refuse.
- Output names the file to commit; repeated init preserves bytes and never installs/replaces a lefthook launcher.
- Launcher: [official lefthook v1.11.13 template](https://github.com/evilmartians/lefthook/blob/v1.11.13/internal/templates/hook.tmpl), rendered for pre-commit without rc, fixed binary, extensions, roots or installation assertions. Tests do not execute/install lefthook or use network.
- Jobs under pre-push remain supported; top-level and pre-commit jobs refuse.
- Valid config symlinks and broken links under all four names refuse before questions/writes, preserving link/target/modes and .git/shipcraft.
- Local variants, competing formats, .config sources, remotes, rc and defined LEFTHOOK_CONFIG (even empty) refuse without writes.
- Whole-file block layout only: flow, inline empty commands, quoted keys, anchors, merge keys and document terminators refuse; symbols inside strings work.
- Insertion preserves CRLF, comments, multiline shell and commands indentation. Empty block commands gets priority 1.
- Failure after integration restores the complete byte/mode snapshot, including .git/shipcraft and both indentation variants.
