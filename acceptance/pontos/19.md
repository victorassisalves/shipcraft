## Item 19: suite roots

The text-only PR path this item started with was removed; only the suite-root cases remain.

- Root spellings docs, ./docs, docs/, ./docs/, docs/./, ././docs and docs// all execute the green base, execute the suite and refuse a red HEAD.
- Parent, case mismatch, symlink, missing, absolute and regular-file roots use safe fallback or current config validation. A valid sentinel suite precedes invalid roots to distinguish execution from directory errors.
