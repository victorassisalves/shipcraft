## Item 19: text-only PRs

- Default is Markdown only. Configured lists replace defaults; empty disables the shortcut; string/number/bool/table values refuse.
- Globs cover *, **, ?, classes, embedded wildcards, root and nested paths.
- Paths cover accents, spaces, quotes, tab/LF/CR/CRLF/U+2028/U+2029, deletion, old/new rename paths, mode/type, symlink and gitlink.
- Base cases cover merge-base, divergent current base config and shallow history without an ancestor.
- Protected content includes tests, support, another suite, .shipcraft.toml, .shipcraft and 40 lefthook sources across root/.config, hidden/local and five extensions. No launcher is simulated; sources change after init.
- Text-only CI skips failing build/check, still judges intermediate history, refuses shortcuts with an open lock, and runs full tests without --pr.
- Text command runs once through a shell at root on HEAD even with dirty worktree. Exit 23, SIGTERM and timeout refuse; CI off skips the command.
- A slot occupied by normal CI does not block text-only CI.
- Local/PR review and shipcraft pr identify text-only review, skip battery setup/execution in the brief, still block on reproduced reading defects, and publish a text summary. No exact phrase is required for the brief instruction.
- Every CI row, including normal/failing text CI, carries boolean text_only. Invalid history whose final diff is only Markdown still records true when its invalid RED cycle was fully reverted.
- Text timeout uses text-check-failed; a signal may appear as a shell exit code.
- `tempo-{pr,ci}-{mensagem,processo}` requires the command and timeout in the last three lines; a delayed marker proves descendants do not survive validation.
- stdout/stderr with/without final LF, success/failure, preserve output, complete announcements and the last three refusal lines.
- Root spellings docs, ./docs, docs/, ./docs/, docs/./, ././docs and docs// all execute the green base and protect docs/contract.md, execute the suite, refuse red HEAD and record text_only=false. Four failed at 612d01d; three were controls.
- Parent, case mismatch, symlink, missing, absolute and regular-file roots use safe fallback or current config validation. A valid sentinel suite precedes invalid roots to distinguish execution from directory errors.
- Normal ./docs/ and docs// retain the Markdown shortcut outside protected globs. Empty/dot roots mean repository root, protecting contract files while allowing guide-only shortcuts.
- Historical ca430b4: six unsafe-root cases escaped; six normal/root controls passed.
