- invalid-{red,green,review}-* cover number, Boolean and array role values, unknown/case-sensitive/space-suffixed agents, missing agents with and without other fields, wrong-type/unknown table agents, one unknown member and reverse-declared unknown members whose alphabetical first key must win.

Existing execution errors retain their old text/code rather than gaining a new dotted path requirement.

Existing execution-invalid and shipcraft-min codes retain their place. Both status and staged hook readers exercise each matrix fixture.
- Minimum guards reject absent, 2.19 and 2.19.999 minima for red/green strings and review tables; accept 2.20, 2.20.0 and 02.020 by numeric comparison; old string review and no roles remain valid at 2.1. - hook-invalid/hook-staged-invalid/hook-staged-valid distinguish ordinary validation, invalid staged config behind a valid working tree, and valid staged config behind an invalid working tree; hook-log-fails keeps the same refusal even when runs.jsonl cannot be written.
- reader-ci/pr/review/merge/base/head cover each public config-reader boundary, an invalid base with a valid committed HEAD, and a valid committed config with an invalid dirty working tree. argv-*-base also changes HEAD's agent/model/effort and still expects base config to drive review.

Each option/value pair precedes the prompt; string and absent fields add no such options, and the captured common brief retains spec/diff markers.

- reuse-same/reuse-agent/reuse-model/reuse-effort distinguish equality of all three identity fields. Candidate metadata is changed only in public JSONL data while retaining real diff/text keys; a changed stub verdict proves whether review ran again or source approval won.
- reuse-null and reuse-legacy test agent-only tables and historical string rows with null/missing fields; reuse-wrong-* reject number/array model, number/Boolean effort, number/object agent and null agent as sources even when defaults would otherwise match. A reused row explicitly copies model/effort (null for missing historical fields), is marked reused and omits after_green_ci.

The absent RED/GREEN wording is exactly "not set (the orchestrator's choice)"; status invokes no provider.

Stderr is captured separately for the stdout contract.
