## Item 24: file-shape warnings

- One literal warning per file in the same summary as Size:, with backtick-quoted path.
- Crossing means before <= N and after > N; already above N or after=N does not warn.
- p90 is rank ceil(0.9*n), without interpolation, on all tracked product files at merge-base, independent of the diff. N needs 20 files; 19 is insufficient, 20/21 works.
- Tests/support matched by globs, seven lockfiles and binaries are neither population nor candidates; Gemfile.lock counts.
- shape_lines comes from current base tip, accepts positive TOML integers and works below 20 files; zero/negative/other types refuse.
- Lines are LF bytes in blobs: CR and a final unterminated line do not count; LFS pointers have their own size.
- Any missing product blob, even outside the diff, cancels measurement, prints Shape: no measurement with reason, and preserves the PR.
- Content-changing rename uses old path for before and new path for output; without detected similarity it is new. Classification uses HEAD path.
- At most five files, descending growth then path bytes; show the remaining count.
- Quoting matches git ls-files without -z and core.quotePath=true even when local config disables it: quote/LF/backslash/non-ASCII escape; literal backtick follows the contract.
- shape_warnings is the untruncated integer total, 0 with measured N/no crossings, null without N/measurement, on existing PR CI/review rows. Shape's exact CI/review count excludes PR/RED/close lifecycle events. Off CI/review layers get no row; shipcraft pr still appends exactly its required PR event, preserving existing log bytes (item 38).
- Compare output/statuses with and without warnings, including refused review. Globs include *, **, embedded wildcard and ?, with matching/nonmatching neighbors.
- Git attributes binary/-diff and configured binary diff drivers exclude .dat without NUL from candidates/population. Native numstat confirms '-' in both columns. They neither inflate p90 nor satisfy minimum population.
- Without attributes, textual or unconfigured drivers keep .dat as text and warn on crossing N.
