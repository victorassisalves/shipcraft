## Item 16b: TypeScript build inference

- Own signals: root/package references or composite true; no extends traversal, nested keys or composite false.
- Only tracked tsconfig files; packages need tracked package.json. Outside-workspace directories do not participate, even with invalid JSONC.
- JSONC covers comments, trailing commas, UTF-8 BOM, CRLF, bare CR and comment delimiters inside strings.
- Invalid root/package JSONC: init succeeds without build, names the file and never compiles.
- npm lists, yarn packages objects, pnpm block/flow/multiline/alias lists; valid manifests contribute their union.
- Invalid/nontext lists (including yarn objects) warn in three lines and omit build; a valid root signal cannot hide a malformed manifest.
- Globs: embedded stars, directory boundaries, question marks, inter-directory stars and ** at start/middle/end. Exclusions apply regardless of order.
- Unsupported `{`, `[`, `+(`, `@(`, `!(` wildcard syntax, including YAML patterns, prevents build; three-line warning names the glob and requests manual config.
- Exact command npx --no -- tsc -b, dot for root, alphabetical targets, no unselected packages.
- Real TypeScript compiles every positive fixture before init; output is removed. A transparent probe delegates to the real executable and counts one root invocation with exact arguments.
- Type/reference build errors: init succeeds without build and warns with command, exit and manual setup.
- No signal means no build invocation. Inferred build announces its command on one line; minimum version is read from Cargo, not hardcoded.
- Init preserves all of .git/shipcraft, including sentinels, and writes no runs.jsonl.
- Real npm/TypeScript target versions; no invented external output format.
- Invalid package.json: init --lang node isolates workspace parsing from language detection; warning names package.json and omits build.
- Compiler SIGTERM with/without stdout LF yields exit 143 or signal 15/TERM, never build config.
- shell-space and shell-quotes cover package names with spaces, apostrophes, double quotes, dollars and semicolons, with sorted targets. Parse persisted commands with shlex and measure actual argv independently; equivalent shell quoting is allowed.
- pnpm rejects yarn-style mapping and text/number/null values; workspace-null/yarn-null are malformed lists, not absent manifests, even with valid root composite and successful tsc.
- U+2028/U+2029 terminate // comments. BOM and CRLF are tested separately and together; bare CR is separate.
- Historical check at 1aacce0: 54/61 passed; seven reproduced failures were shell-space/quotes, YAML mapping/null, workspace-null and JSONC LS/PS. Other variants were controls.
- `invalid-{comment,string,garbage,comma}-{root,package}` covers unclosed block comment/string, trailing garbage and leading comma. Real tsc 7.0.2 rejects all (TS1010, TS1002, TS1012/TS1136/TS1005, TS1136). Trailing commas stay valid.
- Each invalid input is checked by real tsc -p before init. Root has composite; package has no own signal. The tsc marker must stay empty during init, with exit 0, no build and a filename diagnostic.
- Closed-comment controls compile once and persist root build, including packages without their own signal.
