## Item 15a.2: single source without root YAML

- Fresh repository per case, without the four root YAML names or installed hooks.
- `.config/lefthook.yml`, `lefthook.toml`, `.lefthook.jsonc`, `lefthook-local.yml` and `.config/lefthook-local.yaml` refuse before questions.
- Defined LEFTHOOK_CONFIG refuses, including empty values and absent files.
- Unreadable .config, broken links and invalid Git includes refuse; fixtures verify actual read/config failure.
- Init in packages/api considers sources at the Git root.
- Refusal is exactly three lines ending with shipcraft check; bytes, links and modes, including .git, are preserved with no new config, workflow, state or hook.
- No source, lefthook.txt and outra/lefthook.yml allow an executable plain hook.
- `fonte-config-arquivo`: a regular .config file remains unchanged; init succeeds with the same plain hook as the control, without creating a workflow.
- `fonte-config-arquivo-com-yaml`: regular .config plus supported lefthook.yml preserves both existing content and lint; adds shipcraft check at priority 2 without a plain hook. Final YAML matches the lefthook-only control.
