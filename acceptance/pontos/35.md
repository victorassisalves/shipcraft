## Item 35: review identity

- SHA-256 covers exact `git diff --raw -z --no-abbrev --no-renames --ignore-submodules=none origin/main HEAD` bytes. Indentation/content/line/mode/binary/-diff/textconv/gitlink changes alter the key.
- Rebase with identical file versions and identical title/body reuses; a base change to the PR's file requires fresh review.
- Raw-diff error, partial error output or empty output requires fresh review and writes no diff_sha256.
- Fresh review records exact 64 lowercase hex diff_sha256. patch_id alone, uppercase, wrong length or wrong type cannot match.
- Reviewer diff contains repository bytes, without diff.external/textconv output or ANSI from color.diff=always.
- Approval/refusal can reuse identical versions and identical title/body with an identical-file-versions description; error requires another attempt.
