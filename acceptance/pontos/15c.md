## Item 15c: hook execution and protection

- Simulated launcher is the real lefthook v1.11.13 template from tools/lefthook15b.py, ending in `call_lefthook run "pre-commit" "$@"`.
- Offline LEFTHOOK_BIN executor runs positive priorities ascending, missing/zero last; runs every command and returns failure if any fails.
- Supported fixtures use block YAML and explicit positive priorities; Shipcraft gets maximum+1.
- Init without a launcher integrates and gives one lefthook install instruction, without installing a plain hook; repeated init and hidden config names behave identically.
- Status requires an executable real launcher and an exact shipcraft check command; absent commands and echo shipcraft check report a missing hook.
- Locks protect the four main names: hook judges the index, CI judges committed bytes.
- Creating lefthook-local.yml under an open lock refuses in hook and CI. Changing tracked local config refuses for all four local names.
- Even a comment changes protected bytes; refusal names lefthook in its last three lines, without requiring a terminal refusal code.
- Project commands run before shipcraft check; their failures keep the hook failing even if Shipcraft executes, without piped behavior.
- Item 13's timing target measures Shipcraft, not arbitrary project commands.
- Real launcher mode 0644 allows integration with one install instruction, preserving launcher and project command; status reports missing execution permission.
