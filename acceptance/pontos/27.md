## Item 27: init preserves workflows

- Existing source-detection controls still apply; init creates no .github directory.
- Rollback fixtures block .shipcraft/locks by making .shipcraft a regular file. Init may write .shipcraft.toml before failing; rollback restores all tree/.git bytes and modes and creates no .github.
- Lefthook integration does not write .git/hooks, so an unwritable hooks directory is not a suitable failure injection there.
- The English guide is docs/github-ci.md; document checks require enabling GitHub CI, copying its workflow, setting SHIPCRAFT_URL, base-config judgment and explicit setup limits.
