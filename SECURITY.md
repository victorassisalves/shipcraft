# Security

Report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue.

Include the Shipcraft version (`shipcraft --version`), what an attacker or a misbehaving agent can do, and the steps to reproduce it. You will get an answer within a week.

Shipcraft's threat model is the honest agent that makes mistakes or takes shortcuts, not an adversary with write access to the repository (see the README). A way for an agent to get a change past the lock without a visible trace is in scope.

Only the latest release gets fixes.
